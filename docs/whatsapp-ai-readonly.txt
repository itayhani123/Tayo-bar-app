TIMEOUT / COST / DELIVERY
Model deadline 25 seconds, task TTL 20 minutes, max 2 attempts, one global AI lease.
Channel quotas: 6 attempts/minute/user, 40/day/user, 300/day globally, separate from
app quotas. Existing engine max 4 rounds/6 tools/1400 output tokens per round.
Bounded data snapshot and 3800-char answer, no model provider retries or chat history.
Domain fragments, mutation words, numeric/multiline questions, bare choices and
quoted replies stay on the conservative report/clarification path.
AI failure cannot skip remaining report intake in the same Webhook envelope.
Answers are saved before send. A provider ACK for an already-issued request is still recorded while AI is off;
recording delivery does not authorize another send. Unknown external delivery is delivery_unknown and
NEVER automatically resent. No attendance template is used for AI outside its window.
The database gate prevents a model already running from creating a later send after
shutdown, and revisions prevent revival after re-enable. A Meta HTTP request already
issued cannot be recalled. There is also an unavoidable non-atomic boundary between
the final database authorization and issuing an external request: no distributed
transaction with Meta is claimed. Monitor in-flight sends when declaring quiescence.
